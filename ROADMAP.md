- [x] **9. Experiment tracking** — COMPLETE: `mlops/tracking.py` logs every run to the `fraud-intel` MLflow experiment (params, temporal-split PR-AUC/ROC-AUC, model artifact, exact feature list). Wired into both training scripts; `dvc repro` validates end-to-end. Store is local `./mlruns` (gitignored).
- [x] **10. Model selection** — COMPLETE: promotion gate (D7) applied to XGBoost. Operating threshold (F1 on validation) = 0.798; hold-out precision 0.511 / recall 0.483; all 10 key slices pass PR-AUC floor; gate G1+G2+G3 all pass → **promoted**. Registered in MLflow Model Registry as `fraud-intel-champion` v1 (alias `champion`). Report in `artifacts/models/promotion_report.json`.
- [x] **11.
